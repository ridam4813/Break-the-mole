# 🐹 Break the Mole

A fun and interactive **Break the Mole / Whack-a-Mole** browser game built using **HTML, CSS, and JavaScript**.

The goal is simple: **hit as many moles as possible before the 30-second timer runs out!**

---

## 🎮 Features

- 🐹 Animated moles
- 🎯 Random mole appearances
- ⏱️ 30-second countdown
- 🏆 High-score system
- 🔥 Combo scoring
- 📈 Increasing difficulty
- 💥 Hit animations
- 🔊 Hit sound effects
- 📱 Responsive mobile design
- 💾 High score saved using `localStorage`
- ⌨️ Spacebar support
- 🌙 Modern arcade-style UI
- 🚫 No external libraries required
